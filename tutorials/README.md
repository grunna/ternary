# Tutorials

These short practical guides introduce Ternary Lab. Start with the first and work forward; every guide uses components already available in the simulator.

| Guide | Prerequisites | Goal |
| --- | --- | --- |
| [1. Your first circuit](01-your-first-circuit.md) | None | Connect a trit input to a visible output. |
| [2. Create a reusable component](02-reusable-component.md) | Tutorial 1 | Build a small block with a clear external port. |
| [3. Run and debug a program](03-cpu-program.md) | Basic editor familiarity | Load, step, and inspect a CPU program. |
| [4. Debug signals and the CPU](04-debugging.md) | Tutorial 3 | Find where a value changes with simulator tools. |

The screenshots show example projects; menus and panels can contain slightly different items depending on the active demo.

See the [README](../README.md) for an overview, the [ISA](../ISA.md) for instructions, and the [ROADMAP](../ROADMAP.md) for upcoming project work.
